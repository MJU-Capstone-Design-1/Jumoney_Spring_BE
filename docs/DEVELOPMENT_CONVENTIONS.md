# Development Conventions

본 문서는 기능별 명세와 별개로, 공통 구현 컨벤션을 정리합니다.

## AI Assistant Context (공통 구현 규칙)
1. **메서드 역할 분리**: 컨트롤러와 서비스 클래스에서 반복되거나 책임이 분명한 로직은 같은 파일 내부의 private 메서드로 분리한다.
2. **구역 주석 사용**: 분리한 메서드는 클래스 하단에 `// ========== 인증 메서드 ==========`, `// ========== 조회 메서드 ==========`, `// ========== 검증 메서드 ==========`, `// ========== 비즈니스 로직 메서드 ==========` 형식의 구역 주석으로 정리한다.
3. **컨트롤러 기준**: 인증 사용자 추출, 요청 파라미터 조합, 반복되는 예외 처리는 컨트롤러 하단 private 메서드로 분리해 재사용한다.
4. **서비스 기준**: 엔티티 조회, 사전 검증, 복잡한 계산/조합 로직은 서비스 하단 private 메서드로 분리하고 public 메서드는 흐름이 보이도록 유지한다.
5. **우선 원칙**: 새로운 클래스나 유틸로 빼기 전에, 먼저 현재 파일 내부에서 역할별 private 메서드 분리로 해결 가능한지 우선 검토한다.
