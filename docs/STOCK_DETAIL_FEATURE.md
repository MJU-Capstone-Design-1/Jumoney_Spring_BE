# Stock Detail & Chart Specification

본 문서는 '주머니'의 종목 상세 정보 조회 및 시계열 차트(분/일/주/월/년) 생성 로직을 정의합니다.

## AI Assistant Context (개발 원칙)
1. **아키텍처 일관성**: Spring Boot는 KIS 웹소켓을 직접 호출하지 않는다. 실시간 데이터는 Node.js가 수집하여 Redis에 적재한 값을 사용한다.
2. **차트 데이터 결합 (DB + Redis Hybrid)**: 차트를 그릴 때 무거운 과거 데이터는 반드시 RDBMS(`StockPrice`)에서 조회한다. 인메모리(Redis)는 오직 '현재 장 중에 변하고 있는 최신 데이터(오늘의 캔들)'만 담당하며, Spring Boot가 DB 데이터의 마지막에 Redis 데이터를 이어 붙여 프론트엔드로 응답한다.

## 1. 기업 상세 정보 조회
- **기능**: 기업명, 실시간 시세, 전일 대비 등락률, 거래량 및 주요 재무 지표 조회.
- **사용 테이블**: `Stock`, `StockIndicator`, `StockPrice`
- **로직**:
    1. **기본 정보**: `Stock` 테이블에서 `name`, `imageFileName`, `description` 및 섹터 정보를 조회.
    2. **실시간 데이터**: Redis에서 최신 현재가, 등락률, 누적 거래량(`ACML_VOL`) 조회.
        - Redis 미존재 시: DB `StockPrice`의 최신 종가와 `StockIndicator`의 거래량 데이터를 Fallback으로 사용.
    3. **상세 재무 지표**: `StockIndicator` 테이블 또는 `FHKST01010100` API로 사전 적재된 데이터 조회.
        - 당일 최고/최저가, 52주 최고/최저가, PER, PBR, EPS 등.

## 2. 차트 그리기 (시계열 데이터)

### 2.1. 1분봉 차트 (당일)
- **범위**: 당일 09:00 ~ 현재 시간 (X축: HHMM)
- **로직 (Redis 중심)**:
    - 1분봉은 당일(하루 최대 390개) 동안 매우 빈번하게 갱신되므로 예외적으로 Redis ZSET(`chart:1min:{code}`)을 주력으로 사용한다.
    1. **데이터 소스**: 상세 페이지 진입 시 Redis ZSET에서 오늘 누적된 분봉 리스트를 조회.
    2. **실시간 업데이트**: Node.js가 쏜 실시간 틱 데이터를 Spring이 ZSET의 마지막 요소로 갱신하여 차트 끝점을 유지.
    3. **정합성 보정**: Spring 스케줄러가 1분마다 `FHKST03010200`(분봉조회) API를 호출하여 확정된 분봉 1개를 ZSET과 DB(`StockPrice`)에 최종 동기화.

### 2.2. 기간별 차트 (일/주/월/년)
- **범위**: 일(최근 3개월), 주(최근 1년), 월(최근 5년), 년(전체)
- **로직 (DB + Redis 하이브리드)**:
    1. **과거 데이터 로드 (DB)**: `StockPrice` 테이블에서 해당 종목의 어제까지 확정된 캔들 리스트를 조회한다. (DB 쿼리로 LIMIT/날짜 필터링)
    2. **현재 캔들 로드 (Redis)**: 현재 장이 열려있는 경우, Redis에서 실시간 현재가, 고가, 저가, 시가 정보를 가져와 '오늘의 캔들(미확정)' 객체를 하나 만든다.
    3. **데이터 결합**: Spring Boot의 Service 단에서 `DB 데이터 리스트 + Redis 미확정 캔들 1개`를 하나의 리스트로 병합(Merge)하여 반환한다.
    4. **장 마감 동기화**: 장 마감 후 스케줄러를 통해 오늘 확정된 캔들을 DB `StockPrice`에 Insert 하여 다음날부터는 과거 데이터로써 DB에서 꺼내 쓰도록 한다.

## KIS API 연동 명세 (Spring Boot 백엔드용)

구현 시 `kis_api` 폴더의 상세 명세 마크다운을 반드시 참고하며, 아래 `tr_id`를 기반으로 REST API를 호출한다.

**1. [국내주식] 기본시세 - 주식현재가 시세 (REST)**
- **tr_id**: `FHKST01010100`
- **용도**: 상세 페이지 진입 시 Redis가 비어있을 경우의 시세 보정 및 주요 재무 지표(PER, 52주 고가 등) 수집.

**2. [국내주식] 기본시세 - 주식당일분봉조회 (REST)**
- **tr_id**: `FHKST03010200`
- **용도**: 1분봉 차트 초기화 및 1분 단위 확정 분봉 데이터 동기화.
- **응답 데이터**: `stck_cntg_hour`(시간), `stck_prpr`(종가), `stck_oprc`(시가), `stck_hgpr`(고가), `stck_lwpr`(저가).

**3. [국내주식] 기본시세 - 국내주식기간별시세 (REST)**
- **tr_id**: `FHKST03010100`
- **용도**: 일/주/월/년봉 과거 데이터 수집 및 장 마감 후 최종 데이터 확정.
- **파라미터**: `FID_PERIOD_DIV_CODE` (D:일, W:주, M:월, Y:년).
