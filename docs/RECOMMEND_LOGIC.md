# Recommend Logic Design Specification

본 문서는 '오늘의 호주머니'와 '거장의 선택' 추천 알고리즘 및 KIS API 연동 필드 매핑을 정의합니다.

## AI Assistant Context
- AI는 본 문서를 바탕으로 QueryDSL 동적 쿼리 및 Batch 스케줄링 로직을 구현해야 한다.
- 각 지표별로 매핑된 KIS API의 `tr_id`와 응답 데이터 필드명을 정확히 인지하고 DB 엔티티 및 DTO에 반영하라.
- 초단기 데이터인 `체결강도`는 DB가 아닌 **Redis**를 활용하여 처리한다. 추천 후보가 확정된 뒤 REST `FHKST01010300`으로 후보 종목만 조회하고 짧게 캐싱한다.
- 무거운 HTS 조건검색 및 재무지표 필터링은 Batch Job을 통해 사전에 DB(`StockIndicator`)에 적재된 데이터를 조회하는 방식으로 성능을 최적화한다.

## 1. 오늘의 호주머니

### 1.1. 알고리즘 (설문 기반)
**설문 1. 당신의 투자 목적은 무엇인가요?**
- **안정적인 자산 보호** 선택 시:
    - **시가총액** 상위 50위 → `FHKST01010100`(주식현재가 시세)의 `hts_avls`(시가총액)
    - **부채비율** 100% 이하 → `FHKST66430300`(국내주식 재무비율)의 `lblt_rate`(부채비율)
    - **최근 3개년 영업이익** 0 이상 (흑자) → `FHKST66430200`(국내주식 손익계산서)의 `bsop_prti`(영업이익)
- **배당 수익** 선택 시:
    - **시가배당률** 4% ~ 8% → `HHKDB669102C0`(예탁원정보(배당일정))의 `per_sto_divi_amt`(현금배당금)을 현재가로 나누기
    - **배당성향** 25% ~ 80% → `HHKDB669102C0`의 `per_sto_divi_amt`(주당배당금 합계)를 `FHKST66430300`의 `eps`(주당순이익)로 나누어 계산
- **자산의 꾸준한 성장** 선택 시:
    - **ROE** 8% 이상 → `FHKST66430300`(국내주식 재무비율)의 `roe_val`(자기자본이익률)
    - **EPS 성장률** 5% 이상 → `FHKST66430300`(국내주식 재무비율)의 올해 `eps`(주당순이익)와 작년 `eps`(주당순이익)로 계산
- **시세 차익** 선택 시:
    - **PER** 10배 이하 → `FHKST01010100`(주식현재가 시세)의 `per`
    - **PBR** 1배 이하 → `FHKST01010100`(주식현재가 시세)의 `pbr`
    - **영업이익 증가율** 0% 이상 → `FHKST66430300`(국내주식 재무비율)의 `bsop_prfi_inrt`(영업이익증가율)

**설문 2. 어느 정도의 위험을 감수할 수 있나요?**
- **매우 낮음 (안전형)** 선택 시:
    - **베타(β)** 0.7 이하 → `HHKST03900400`(HTS 조건검색)의 [지수 베타계수 범위] > [0.0 ~ 0.7]
    - **볼린저 밴드** 등락폭 범위 15% → `HHKST03900400`(HTS 조건검색)의 [Bollinger Bands 등락폭 범위] > [상한밴드 60봉 동안의 등락폭 0~15%]
- **낮음 (안전추구형)** 선택 시:
    - **베타(β)** 1.0 이하 → `HHKST03900400`(HTS 조건검색)의 [지수 베타계수 범위] > [0.0 ~ 1.0]
    - **볼린저 밴드** 등락폭 범위 15% → `HHKST03900400`(HTS 조건검색)의 [Bollinger Bands 등락폭 범위] > [상한밴드 60봉 동안의 등락폭 0~25%]
- **높음 (수익추구형)** 선택 시:
    - **베타(β)** 1.0~1.2 → `HHKST03900400`(HTS 조건검색)의 [지수 베타계수 범위] > [1.0 ~ 1.2]
    - **상대강도(RSI)** 50~65 → `HHKST03900400`(HTS 조건검색)의 [RSI 구간] > [50 ~ 65]
- **매우 높음 (공격투자형)** 선택 시:
    - **베타(β)** 1.1 이상 → `HHKST03900400`(HTS 조건검색)의 [지수 베타계수 범위] > [1.1~2.0]
    - **상대강도(RSI)** 60 이상 → `HHKST03900400`(HTS 조건검색)의 [RSI 구간] > [60~100]

**설문 3. 선호하는 투자 호흡(기간)은 어떻게 되나요?**
- **초단기(1일)** 선택 시:
    - **체결강도** 상위순 정렬 → `FHKST01010300`(주식현재가 체결)의 `tday_rltv`(당일 체결강도). 후보 종목만 온디맨드 조회 후 Redis에 짧게 캐싱
- **단기(1주일)** 선택 시:
    - **거래대금** 상위순 정렬 → `FHKST01010100`(주식현재가 시세)의 `acml_tr_pbmn`(누적 거래 대금)
- **중기(3달)** 선택 시:
    - **EPS 성장률** 상위순 정렬 → `FHKST66430300`(국내주식 재무비율)의 올해 `eps`와 작년 `eps`로 계산
- **장기(1년)** 선택 시:
    - **ROE** 상위순 정렬 → `FHKST66430300`(국내주식 재무비율)의 `roe_val`(자기자본이익률)

### 1.2. 로직 (Process)
1. 배치 작업으로 200 종목의 **지표 데이터(시가총액, 부채비율, 영업이익, 현금배당금, 계산 배당성향, ROE, 올해 EPS, 작년 EPS, PBR, PER, 영업이익증가율, 누적 거래대금, 250일 최고가 대비 현재가 비율, 매출액, 전체 융자 잔고 비율, 기관계 순매수 수량)**를 DB에 저장
2. 배치 작업으로 HTS 조건검색 API를 호출하여 필터링된 종목을 DB에 저장 (종목 테이블에 있는 코스피 종목만 저장)
3. 네이버 뉴스 API를 호출하여 뉴스를 받아오고, 이를 LLM에 넣어 호재가 예상되는 섹터(종목) 추출
4. 유저가 설문 진행
5. 선택지에 따라 유저 성향 진단
6. 선택지에 따라 종목 필터링 (HTS로 필터링한 종목에 지표 데이터로 필터링)
7. 최종 추천 종목 리스트에서 호재 섹터는 따로 분류

### 1.3. 성능 최적화
1. 재무지표 데이터는 주에 한번만 배치 작업 수행 (실제 재무지표 데이터는 분기에 한번 업데이트됨)
2. HTS 조건검색 API도 배치 작업을 수행하여 미리 종목 추출

## 2. 거장의 선택

### 2.1. 알고리즘 (거장별 지표)
**워런 버핏**
- **지표**
    - **ROE** 15% 이상 → `FHKST66430300`(국내주식 재무비율)의 `roe_val`
    - **PER** 0배 초과 15배 이하 → `FHKST01010100`(주식현재가 시세)의 `per`
    - **EPS 성장률** 10% 이상 → `FHKST66430300`(국내주식 재무비율)의 올해 `eps`와 작년 `eps`로 계산
    - **부채비율** 100% 이하 → `FHKST66430300`(국내주식 재무비율)의 `lblt_rate`(부채비율)
    - **영업이익률** 20% 이상 → 국내주식 손익계산서 (`FHKST66430200`)의 `bsop_prti`(영업이익)을 `sale_account`(매출액)으로 나누기
- **정렬 기준**
    - **ROE** 내림차순

**피터 린치**
- **지표**
    - **PEG** 1.0 이하 → `FHKST01010100`(주식현재가 시세)의 `per`을 `FHKST66430300`(국내주식 재무비율)의 `eps`로 구한 EPS 성장률로 나누기
    - **EPS 성장률** 20% ~ 50% → `FHKST66430300`(국내주식 재무비율)의 올해 `eps`와 작년 `eps`로 계산
    - **부채비율** 100% 이하 → `FHKST66430300`(국내주식 재무비율)의 `lblt_rate`(부채비율)
    - **매출액 증가율** 10% 이상 → 국내주식 손익계산서 (`FHKST66430200`)의 올해 `sale_account`(매출액)와 작년 `sale_account`(매출액)로 계산
    - **섹터** 선택 → 사용자가 고른 섹터로 DB에서 종목 필터링
- **정렬 기준**
    - **PEG** 오름차순

**레이 달리오**
- **지표**
    - **올웨더 포트폴리오** (섹터 분산) → 4개의 섹터 별로 균등하게 종목 추출 (기본값 예시: IT/반도체, 에너지/화학, 금융, 필수소비재)
    - **PER** 20배 이하 → `FHKST01010100`(주식현재가 시세)의 `per`
    - **신용잔고율** 5% 이하 → `FHPST04760000`(신용잔고 일별추이)의 `whol_loan_rmnd_rate`
    - **부채비율** 50% 이하 → `FHKST66430300`(국내주식 재무비율)의 `lblt_rate`(부채비율)
    - **이익수익률** 3.38(현 국고채 3년물) 이상 → 이익 수익률 = (1/PER)*100
- **정렬 기준**
    - **시가총액** 내림차순

**윌리엄 오닐**
- **지표**
    - **EPS 성장률** 25% 이상 → `FHKST66430300`(국내주식 재무비율)의 올해 `eps`와 작년 `eps`로 계산
    - **ROE** 17% 이상 → `FHKST66430300`(국내주식 재무비율)의 `roe_val`
    - **52주 신고가** 갱신 또는 10% 근접 → `FHKST01010100`(주식현재가 시세)의 `d250_hgpr_vrss_prpr_rate`(250일 최고가 대비 현재가 비율)
    - **대장주** 여부 → 대장주 여부가 true인 종목 필터링
    - 최근 20거래일 **기관 순매수** 합계 0 이상 → `FHPTJ04160001`(종목별 투자자매매동향)의 `orgn_ntby_qty`(기관계 순매수 수량)
- **정렬 기준**
    - **52주 신고가 대비 현재가 비율** 내림차순

### 2.2. 로직 (Process)
1. 배치 작업으로 200 종목의 **지표 데이터(시가총액, 부채비율, 영업이익, 현금배당금, 계산 배당성향, ROE, 올해 EPS, 작년 EPS, PBR, PER, 영업이익증가율, 누적 거래대금, 250일 최고가 대비 현재가 비율, 매출액, 전체 융자 잔고 비율, 기관계 순매수 수량)**를 DB에 저장
2. 네이버 뉴스 API를 호출하여 뉴스를 받아오고, 이를 LLM에 넣어 호재가 예상되는 섹터(종목) 추출
3. 유저가 원하는 거장 선택
4. 기본으로 설정된 거장 조건으로 추천 종목 리스트 출력 (호재 섹터는 따로 분류)
5. 사용자가 원하는 특정 조건만을 선택하여 다시 추천 종목 리스트 출력 가능

### 2.3. 성능 최적화
1. 재무지표 데이터는 매일 한번만 배치 작업 수행 (실제 재무지표 데이터는 분기에 한번 업데이트됨)

## 3. API 연동

**1. [국내주식] 기본시세 - 주식현재가 시세**
- **REST**
- **tr_id**: `FHKST01010100`
- **응답 데이터**:
    - `hts_avls`: 시가총액
    - `per`
    - `pbr`
    - `acml_tr_pbmn`: 누적 거래 대금
    - `d250_hgpr_vrss_prpr_rate`: 250일 최고가 대비 현재가 비율 - 추가

**2. [국내주식] 종목정보 - 국내주식 재무비율**
- **REST**
- **tr_id**: `FHKST66430300`
- **응답 데이터**:
    - `lblt_rate`: 부채비율
    - `roe_val`: 자기자본이익률
    - `eps`: 주당순이익 (당기, 전년 동기)
    - `bsop_prfi_inrt`: 영업이익증가율

**3. [국내주식] 종목 정보 - 국내주식 손익계산서**
- **REST**
- **tr_id**: `FHKST66430200`
- **응답 데이터**:
    - `bsop_prti`: 영업이익
    - `sale_account`: 매출액 - 추가

**4. [국내주식] 종목 정보 - 예탁원정보(배당일정)**
- **REST**
- **tr_id**: `HHKDB669102C0`
- **응답 데이터**:
    - `per_sto_divi_amt`: 현금배당금

**5. 계산 지표 - 배당성향**
- **계산식**: `배당성향(%) = 기간 내 주당배당금(DPS) 합계 / 주당순이익(EPS) * 100`
- **원천 데이터**:
    - `HHKDB669102C0`의 `per_sto_divi_amt`: 주당배당금
    - `FHKST66430300`의 `eps`: 주당순이익
- **결측 처리**: DPS 또는 EPS가 없거나 EPS가 0 이하이면 배당성향은 `NULL`로 저장한다.

**6. [국내주식] 시세 분석 - 국내주식 신용잔고 일별추이**
- **REST**
- **tr_id**: `FHPST04760000`
- **응답 데이터**:
    - `whol_loan_rmnd_rate`: 전체 융자 잔고 비율

**7. [국내주식] 시세 분석 - 종목별 투자자매매동향(일별)**
- **REST**
- **tr_id**: `FHPTJ04160001`
- **응답 데이터**:
    - `orgn_ntby_qty`: 기관계 순매수 수량

**8. [국내주식] 시세분석 - 종목조건검색조회**
- **REST, HTS**
- **tr_id**: `HHKST03900400`
- **응답 데이터**:
    - 종목 리스트

**9. [국내주식] 기본시세 - 주식현재가 체결**
- **REST**
- **tr_id**: `FHKST01010300`
- **응답 데이터**:
    - `tday_rltv`: 당일 체결강도
