# 오늘의 호주머니 선택지 및 페르소나 명세

오늘의 호주머니 설문은 3단계 선택으로 구성한다.

1. 투자 목적
2. 위험 감수 수준
3. 투자 기간

사용자가 선택한 `투자 목적 + 위험 감수 수준 + 투자 기간` 조합에 따라 페르소나 명칭과 설명 문구를 제공한다.

## 선택지 코드 기준

### 1차 선택지: 투자 목적

| 코드                   | 화면 문구      |
|----------------------|------------|
| `CAPITAL_PROTECTION` | 안정적인 자산 보호 |
| `DIVIDEND_INCOME`    | 배당 수익      |
| `STEADY_GROWTH`      | 자산의 꾸준한 성장 |
| `CAPITAL_GAIN`       | 시세 차익      |

### 2차 선택지: 위험 감수 수준

| 코드               | 화면 문구 |
|------------------|-------|
| `STABILITY`      | 매우 낮음 |
| `SAFE_PURSUIT`   | 낮음    |
| `PROFIT_PURSUIT` | 높음    |
| `AGGRESSIVE`     | 매우 높음 |

### 3차 선택지: 투자 기간

| 코드            | 화면 문구 |
|---------------|-------|
| `ULTRA_SHORT` | 초단기   |
| `SHORT`       | 단기    |
| `MID`         | 중기    |
| `LONG`        | 장기    |

## 목적별 허용 조합

| 투자 목적      | 허용 위험도               | 허용 기간           | 비고                |
|------------|----------------------|-----------------|-------------------|
| 안정적인 자산 보호 | 매우 낮음, 낮음, 높음        | 단기, 중기, 장기      | `매우 높음`, `초단기` 제외 |
| 배당 수익      | 매우 낮음, 낮음, 높음        | 단기, 중기, 장기      | `매우 높음`, `초단기` 제외 |
| 자산의 꾸준한 성장 | 매우 낮음, 낮음, 높음, 매우 높음 | 단기, 중기, 장기      | `초단기` 제외          |
| 시세 차익      | 낮음, 높음, 매우 높음        | 초단기, 단기, 중기, 장기 | `매우 낮음` 제외        |

> 구현 시에는 아래 페르소나 매트릭스에 존재하는 조합만 유효 조합으로 간주한다.

| 매우 낮음 | 중기 | 단단한 현금 보관자   | 당장 쓸 돈은 아니지만 리스크는 싫어요. 안전한 울타리 안에서 차분하게 자산을 예치합니다.       |
| 매우 낮음 | 장기 | 철벽 수비형 자산가   | 시간이 흘러도 내 자산은 그대로! 변치 않는 가치를 지닌 안전 자산에 묻어두고 마음 편히 지내요.   |
| 낮음    | 단기 | 안전 지대 단기 체류자 | 잃지 않는 것이 최고의 수익! 짧은 호흡으로 시장 상황을 보며 가장 안전한 곳만 골라 다녀요.     |
| 낮음    | 중기 | 신중한 징검다리     | 적당한 기간 동안 원금을 지키는 게 중요해요. 큰 욕심 없이 안전한 투자처를 거쳐 가는 실속파입니다. |
| 낮음    | 장기 | 느긋한 우량주 수집가  | 시간은 내 편! 튼튼한 우량주에 묻어두고 긴 호흡으로 여유롭게 자산을 지켜나갑니다.           |
| 높음    | 단기 | 호기심 많은 방어수   | 기본은 안전하게! 하지만 확실한 단기 수익 기회가 보이면 놓치지 않고 챙기는 타입이에요.        |
| 높음    | 중기 | 전략적 수비 조율사   | 안정적인 베이스 위에 약간의 변동성을 가미해요. 리스크를 관리하며 중기적인 성과를 조율합니다.     |
| 높음    | 장기 | 신중한 성장 탐험가   | 기본기는 탄탄하게 다지고, 미래 성장성이 보이는 산업에는 긴 호흡으로 과감하게 투자해요.        |

| 낮음    | 단기 | 스마트 인컴 추구자 | 단기 자금도 그냥 놀릴 순 없죠. 적절한 리스크를 관리하며 쏠쏠한 배당 수익을 챙기는 실속파입니다.     |
| 낮음    | 중기 | 실속파 배당 수확자 | 적절한 배당 수익률에 만족해요. 너무 큰 욕심 없이 꼬박꼬박 수익을 챙기는 것을 즐깁니다.          |
| 낮음    | 장기 | 느긋한 배당 농부  | 씨앗을 심고 열매를 기다려요. 탄탄한 배당주를 꾸준히 모아 장기적으로 풍성한 결실을 봅니다.         |

### 자산의 꾸준한 성장

|-------|----|-------------|----------------------------------------------------------------------|
| 매우 낮음 | 단기 | 안전 성장 징검다리  | 본격적인 성장을 준비하는 단계예요. 아주 짧은 기간이라도 손실 없이 자산을 지키며 다음 기회를 기다립니다.          |
| 매우 낮음 | 중기 | 안전 성장 지향자   | 크게 벌기보다 안 잃는 게 성장의 시작이죠. 낮은 변동성 속에서 차근차근 자산을 키워나갑니다.                 |
| 매우 낮음 | 장기 | 우직한 거북이 저축가 | 느려도 결국은 이깁니다. 가장 안전한 길을 선택해 아주 긴 시간 동안 눈덩이를 굴리는 타입이에요.               |
| 낮음    | 단기 | 스마트 스텝 업    | 조금씩이라도 확실하게 키워나가요. 큰 위험 없이 단기적인 수익을 쌓아 자산의 기초 체력을 기르는 중입니다.          |
| 낮음    | 중기 | 스마트 가드너     | 나무가 자라듯 자산을 관리해요. 적당한 위험을 관리하며 중기적으로 우상향하는 그래프를 그립니다.                |
| 낮음    | 장기 | 복리의 마법사     | 장기 투자의 힘을 믿어요. 낮은 리스크의 자산을 꾸준히 보유하여 복리 효과를 극대화합니다.                   |

| 높음    | 중기 | 적극적 성장 엔진   | 성장을 위해서라면 어느 정도의 속도감은 필요하죠. 중기적인 트렌드에 올라타 자산을 공격적으로 키웁니다.            |
| 높음    | 장기 | 야심 찬 빌더     | 미래의 큰 가치를 위해 오늘의 변동성을 견뎌요. 높은 성장성이 기대되는 곳에 장기적으로 투자합니다.              |
| 매우 높음 | 단기 | 퀀텀 점프 지향자   | 단기간의 가파른 우상향을 목표로 해요. 큰 변동성을 감수하더라도 자산이 한 단계 도약하는 것을 즐기는 타입입니다.      |
